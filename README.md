# Marimo Shop (マリモショップ) 🌿

「Marimo Shop」は、日々の暮らしに心地よい彩りと温もりを届ける、衣服と生活雑貨のオンラインショッピングサイトです。  
初心者の方でも迷わず直感的にお買い物を楽しめるよう、親しみやすく明るいデザインとシンプルな操作性を重視して設計されています。

---

## 🌟 サイト概要とコンセプト

- **ナチュラル＆ボタニカルな世界観**  
  温かみのあるフォレストグリーン（#2D5A46）と生成り色（#FAF8F5）を基調とし、実際のセレクトショップを訪れたような心地よいショッピング体験を提供します。
- **外部依存のない安心・高速設計**  
  外部CDNや外部API、重量級フレームワークを使わず、ピュアな HTML5 / CSS3 / Vanilla JavaScript のみで構築。オフライン環境でも動作します。
- **オリジナルSVG商品画像**  
  リネンシャツや益子焼マグカップなど、12点のサンプル商品はすべて高精細なベクターSVGイラストで描画されており、どの解像度の画面でも美しく鮮明に表示されます。
- **スマートフォン完全対応（レスポンシブ）**  
  PCの大画面はもちろん、スマートフォンの画面でも商品が探しやすい2カラム表示、固定フッターナビゲーション、スライドイン式のカートドロワーを採用しています。

## 🛍️ 実装されている主な機能

### 1. 商品一覧・絞り込み・検索
- **カテゴリー絞り込み**:
  - すべて
  - 衣服（トップス、ボトムス、アウター）
  - 生活雑貨
  - アクセサリー
- **並び替え（ソート）**:
  - おすすめ順
  - 価格が安い順
  - 価格が高い順
  - レビュー評価順
- **リアルタイム検索**:
  - 商品名やキーワードで瞬時にインクリメンタル絞り込み

### 2. ショッピングカート機能
- **ワンクリック追加**:
  - 商品カードの「カートに入れる」ボタンで即座に追加
  - 画面下部に「○○をカートに追加しました」トースト通知を表示
  - ヘッダーおよびスマホ下部バーのカートバッジに合計点数をリアルタイム反映
- **スライドイン カートドロワー**:
  - 画面右側からスムーズに開閉
  - 商品ごとの画像・商品名・単価・数量変更（`＋` / `−`）・小計表示
  - 商品ごとの個別削除（`🗑️ 削除`）および一括クリア（`カートを空にする`）
- **送料無料プログレスゲージ**:
  - 合計5,000円（税込）以上で全国送料無料
  - 「あと○○円で送料無料になります」の進捗バーを動的に表示
- **LocalStorage連携**:
  - ブラウザをリロードしたり閉じたりしてもカート内容が保持されます

### 3. ご注文手続き ＆ 注文完了（サンクス）画面
- **ご注文手続きモーダル**:
  - ご注文内容・小計・送料・合計金額の最終確認サマリー
  - お届け先情報（お名前、お電話番号、メールアドレス、郵便番号、ご住所）の入力
  - お届け希望時間帯の指定（午前中、午後、夜間など）
  - お支払い方法の選択（クレジットカード、コンビニ決済、代金引換、銀行振込）
  - 入力必須項目のリアルタイムバリデーション
- **注文完了メッセージ**:
  - 注文確定時にユニークな注文番号（例: `MRM-20261029-XXXX`）を自動発行
  - ご注文日時、お届け先、決済方法、合計金額の完了画面を表示
  - 注文確定に伴うカートの自動クリア
  - 「お買い物を続ける」ボタンで元のショップ画面へスムーズに戻る遷移

## 🚀 起動方法とアクセス手順

本環境では、コンテナ内のポート80（`0.0.0.0:80`）でWebサーバーが待機しています。

### 1. Webサーバーの起動

もしサーバーが停止している場合は、作業フォルダ（`/var/www`）内で以下のコマンドを実行します。

```bash
# 方法1: 付属のPythonサーバースクリプトを実行（推奨）
python3 /var/www/server.py

# または方法2: Python標準のhttp.serverモジュールで起動
python3 -m http.server 80 --bind 0.0.0.0
```

### 2. Webブラウザでのアクセス

ブラウザを開き、以下のURLにアクセスしてください。

- ローカルホストからアクセスする場合:
  ```
  http://localhost/
  ```
  または
  ```
  http://127.0.0.1/
  ```

- コンテナのIPアドレス宛てにアクセスする場合:
  ```
  http://<コンテナのIPアドレス>/
  ```

### 3. サーバーの停止方法

ターミナルで `Ctrl + C` を押すとサーバーを安全に終了できます。
バックグラウンド実行している場合はプロセス番号を確認して終了します。
