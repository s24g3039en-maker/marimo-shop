オンラインショップ「Marimo Shop」開発・実装報告書

衣服・生活雑貨のWebアプリケーション開発課題

提出日: 2026年10月29日
Webサーバー: 0.0.0.0:80 稼働中

1. サイトの目的

「Marimo Shop」は、「日々の暮らしに、心地よい彩りと温もりを。」をテーマに、衣服やナチュラルな生活雑貨を届けるオンラインショップです。Web操作に不慣れな初心者やスマートフォンユーザーでも、迷うことなく安心して直感的にお買い物を完結できるよう、親しみやすく明るいデザインと簡潔な操作動線の実現を目的として開発しました。

2. サイトの特徴

🌿 温かみあるセレクトショップUI

アースグリーンと生成り色を基調とし、実際の雑貨店のような清潔感と上質さを演出。写真代替として高品質なオリジナルSVGイラストを採用し、完全自己完結型で高速・鮮明に表示。

📱 スマホ完全対応（レスポンシブ）

PC・タブレット・スマートフォンに完全対応。モバイルでは2カラム商品グリッドと下部固定ナビゲーションにより、親指ひとつで快適に商品を閲覧・購入可能。

3. 主な実装機能

機能分類 機能の概要と工夫点
商品一覧・絞り込み 衣服（トップス・ボトムス・アウター）、生活雑貨、アクセサリーのカテゴリ切り替え、おすすめ・価格順・評価順ソート、インクリメンタルキーワード検索を実装。
カート（スライドドロワー） 右側から滑らかに展開。商品ごとの数量変更（＋／−）、個別削除、カート一括クリア、トースト通知、LocalStorageによる画面更新時のカート保持。
送料無料プログレスゲージ 「5,000円以上で送料無料」特典。現在額に応じた動的プログレスバーを表示し、ユーザーの購買意欲と利便性を向上。
購入手続き・注文完了 注文サマリー確認、お届け先フォーム（入力チェック付き）、4種類の決済選択。確定時に一意の注文番号を発行し、完了画面の表示とカートクリアを実行。

4. 使用技術 (Tech Stack)

フロントエンド HTML5（セマンティック構文）、CSS3（Flexbox, CSS Grid, 変数, レスポンシブ設計）、Vanilla JavaScript (ES6+, DOM API, LocalStorage) ※外部ライブラリ非依存
アセット / 配信基盤 SVG 1.1（自作ベクター画像12点）、Python 3（http.server、0.0.0.0:80バインド）
